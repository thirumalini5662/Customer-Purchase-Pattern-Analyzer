# Customer-Purchase-Pattern-Analyzer
Analyzed customer purchase behavior using SQL and Power BI to identify spending trends, top customers, product performance, and payment preferences through an interactive dashboard.

Project Overview

The Customer Purchase Pattern Analyzer is a retail analytics project designed to analyze customer buying behavior, spending trends, product performance, and payment preferences using SQL and Power BI.

This project demonstrates the complete data analytics workflow including data preparation, SQL analysis, KPI generation, dashboard development, and business insight extraction.

Objectives

- Analyze customer purchasing patterns
- Identify top-spending customers
- Evaluate product performance
- Understand city-wise sales trends
- Analyze payment method preferences
- Create an interactive Power BI dashboard

Tools & Technologies

- Microsoft Excel
- MySQL
- Power BI
- SQL

Dataset Information

The dataset contains 300 customer transaction records with the following fields:

- Customer_ID
- Product
- Purchase_Date
- Purchase_Amount_INR
- Payment_Mode
- City

SQL Analysis Performed

- Total Revenue Analysis
- Customer Count Analysis
- Average Spending Analysis
- Top 10 Customer Identification
- Product-wise Revenue Analysis
- City-wise Revenue Analysis
- Payment Mode Distribution
- Purchase Frequency Analysis

Power BI Dashboard Features

KPI Cards

- Total Revenue
- Total Customers
- Total Transactions
- Average Spend

Visualizations

- Sales by City
- Product Revenue Analysis
- Payment Mode Treemap
- Sales Trend Analysis
- Top Customers Table
- Product Contribution Analysis

Interactive Filters

- City
- Product
- Payment Mode

Key Insights

- Identified high-value customers contributing significantly to total revenue.
- Analyzed customer spending trends across multiple cities.
- Evaluated top-performing products by revenue.
- Examined payment mode preferences among customers.
- Built an interactive dashboard for business decision-making.

Business Impact

The project demonstrates how retail businesses can leverage customer transaction data to improve customer retention, optimize product strategy, and enhance marketing effectiveness through data-driven decision-making.
